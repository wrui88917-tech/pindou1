# 任天堂 · 时间之线

根据《任天堂冷知识 · VibeCoding 连续可视化方案》制作，采用其中更详细的毫秒级事件表安排 120 秒时间线。

## 两个成片

- [有配乐版](../../exports/nintendo-timeline-music-120s-4k.mp4)：原创氛围钢琴、柔和垫音、后段轻电子脉冲，加少量纸张、毛笔、金属风声与启动音效。
- [无配乐版](../../exports/nintendo-timeline-no-music-120s-4k.mp4)：只保留同一组少量音效，未添加背景音乐或持续节拍。

两个版本均无解说、无人声；画面完全相同。规格为 120 秒、3840×2160、24fps、H.264 + AAC。

## 连续可视化

深棕纸纹、低饱和金色时间线始终连接叙事。660 个确定性粒子在花札纹样、铁塔钢架、机械玩具和游戏机轮廓之间连续插值变形。画面仅保留年份、地点、物件名及关键词，没有长句解说字幕。

| 时间 | 内容 |
| --- | --- |
| 0–6 秒 | 纸纹、Nintendo、1889，时间线展开 |
| 6–15 秒 | 京都花札小店 |
| 15–25 秒 | 花札花纹 |
| 25–35 秒 | 花纹变为埃菲尔铁塔线条 |
| 35–45 秒 | 京都与巴黎，同一年两个世界 |
| 45–55 秒 | 纸牌之后：速食米与出租车 |
| 55–65 秒 | 超怪手与玩具制造 |
| 65–75 秒 | 1983 红白机 |
| 75–85 秒 | 1989 Game Boy |
| 85–95 秒 | 2006 Wii |
| 95–105 秒 | 2017 Switch |
| 105–115 秒 | 像素与轮廓回流为花札 |
| 115–120 秒 | 时间线收束，回到 1889 |

京都、巴黎的水彩画为生成的历史示意插画，不是历史照片；4K 视频中的插画含放大处理，文字与矢量轮廓以 4K 画布绘制。1889 年场景无现代游戏机，埃菲尔铁塔为无现代彩灯的白天形象，花札采用花卉纹样。未使用存在史料争议的酒店说法；超怪手按机械玩具表现。

## 可编辑工程

`animation.js` 保存完整 Canvas 绘制与连续形变；`index.html` 登记 HyperFrames 时间轴，默认音轨为配乐版。`assets/music-and-effects.m4a` 和 `assets/effects-only.m4a` 是独立的两个音轨，可直接替换 `<audio>` 的 `src` 切换。

需要 Node.js 22+、FFmpeg、Chromium 和 Noto Serif CJK SC 字体。

```sh
npm run check
npm run dev
```

动画按时间确定性绘制，不依赖实时播放速度。`window.renderFrame(seconds)` 可精确跳转，播放与声音同步可由 HyperFrames Studio 管理。

## 验证范围

HyperFrames 工程检查通过；另外提取了 13 个关键帧并人工抽查关键分镜，因为 Canvas 内部文字不属于自动 DOM 文字检查范围。

最终两个 MP4 均完整解码通过，均为 2880 帧、120 秒、4K、24fps。视频流 SHA-256 一致，确认两个版本的画面完全相同；无配乐音轨已检查音效间隙为静音，配乐版在同一间隙包含音乐。
