# 我，和一条没回的消息 · 我终于不用再说“我挺好的”

110 秒，1080×1920，30fps。沿用原片第一人称 Canvas 手绘、手机对话、咖啡店暖色与暗色卧室风格。

[下载确认结尾版 MP4](../../exports/unanswered-message-final-110s.mp4)

## 结尾

见面之后，阿杰问“到家了吗”。这一次，“我”删掉“我挺好的”，坦白最近有些难。阿杰没有继续在聊天框里安慰，而是直接打来电话。

通话对白以字幕呈现：

> 阿杰：工作怎么了？
>
> 我：也没出什么大事，就是……有点累。
>
> 阿杰：嗯，我听着。

手机被举到耳边，镜头留在卧室暖灯，再慢慢移向窗外。许多窗仍亮着，其中一扇暖窗里有人正在通话。

片尾字幕：

> 那晚，事情一件也没解决。
>
> 但我终于不用把“我挺好的”，再说一遍。

保留合成配乐、消息提示、来电和接通音效，没有新增人声配音。片尾音画渐隐。
