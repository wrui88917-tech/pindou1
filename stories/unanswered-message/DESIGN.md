# 原片视觉延续

## Style Prompt
保留上传原片的第一人称 Canvas 手绘风格：手机、手指、呼吸感手持镜头、眨眼、聊天气泡、暖色咖啡店与暗色卧室。结尾从咖啡店的余温转到到家后的一次坦诚对话，接起语音通话，镜头移向城市窗景，以坦诚代替逞强，留白收束。

## Colors
- #161d33 暗色底
- #f4efe6 暖白文字
- #ffb86b 琥珀重点与自己发送的气泡
- #2d3558 朋友消息
- #c98f62 咖啡店暖光

## Typography
延续原片 PingFang SC / Microsoft YaHei / Noto Sans SC 与等宽时间标记。

## What NOT to Do
- 不增加营销口号、片尾关注按钮或旁白人声
- 不替换原片人物和前段情节
- 不用密集特效挤掉读消息的时间

## Timing
总时长 110 秒。0–67 秒沿用原片；67–110 秒为咖啡余温、坦诚消息、来电接听、暖灯与城市窗口、最终字幕，音效沿用网页合成方案。
