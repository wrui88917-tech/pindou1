# Nintendo 1889 · 连续时间长卷

按《任天堂冷知识-VibeCoding连续可视化方案-MP4版》制作。120 秒，1920×1080，30fps。纯 Canvas 2D 与原生 JavaScript；不下载图片、字体或音源。

深棕纸纹 #241e19；暖象牙 #e9dcc3；低饱和金 #c4a369；红褐铁塔 #a45c46；靛蓝 #637b87；植物灰绿 #8e9a78。系统本地 Noto Serif CJK SC / serif 配合 Georgia 数字，标题至少 56px。

6000 个固定身份粒子，900 个组成时间轴，其余重组为手绘几何物件。物件在横向世界坐标上排列，摄像机连续跟随。相邻目标至少 1.5 秒重组，纸纹从第一帧保留到最后；不做整屏淡出，不使用黑场。水彩感来自粒子携带的半透明颜料晕染。

屏幕文字严格使用文档白名单；所有目标点集初始化时由离屏 Canvas 采样。音频由 OfflineAudioContext 合成；无旁白。保留文档酒店小图标（灰色、不到 1 秒、无文字），仅表示方案中的争议副业符号，不构成史实背书。

禁止：外部图片、GSAP/CDN、外部字体文件、旁白、长句字幕、现代设备提前出场、银灰铁塔、彩灯、全屏切换、全屏淡黑。
