AI豆仓本地浏览器测试包

1. 把压缩包解压到一个文件夹（不要在压缩包里直接运行）。
2. 电脑需已安装 Node.js 22 LTS：https://nodejs.org/ 。
3. 双击“启动测试.cmd”。首次会从 npm 安装 Playwright，需要联网。
4. 脚本用你电脑的 Edge 或 Chrome 打开独立浏览器窗口。没有这两种浏览器时，在本文件夹终端执行 npx playwright install chromium 后重试。
5. 自己在打开的窗口登录AI豆仓，回到命令窗口按回车。无需提供密码给任何人。
6. 脚本生成固定的12×12图纸，上传一次，等待识别并截图、读数。网站改版或控件不匹配时会暂停，按提示手动完成当前一步，再回终端按回车。
7. 脚本不会点击“替换”“保存修改”“发布作品”“记录出库”；但上传/识别可能创建草稿，并消耗网站识别额度或触发网站计费。使用前自行确认账号额度。
8. results 下每次有独立文件夹，包含测试PNG、report.json、报告.txt和截图。请把该文件夹里的报告和截图发回来，不要发送.browser-profile目录。

预期：12列×12行；H7 22颗、E6 29颗、H2 1颗；共52颗，空白92格。
首先测试标准色值版；可在终端执行 node run.mjs --white 测试白底标签版。
pass只代表读到的网格/空白数和网站色号对照状态一致，不代表逐格位置全部验证，也不代表PDF兼容。没有读到的数据标unknown，报告incomplete，绝不自动判成功。
不要为了让报告通过而修改图例、色号或数量。手动校准会记录在报告中。

隐私：独立登录资料仅保存在本机.browser-profile；脚本不导出cookies、不记录密码、不上传报告。截图可能包含账号信息，请检查后分享。退出脚本后可删除.browser-profile来清除登录资料。
这是基于已见截图制作的工具，尚未对真实网站跑通。页面变化可能需要调整。
