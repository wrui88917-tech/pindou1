## Motion Designer Showreel

15 秒、1920×1080、30fps 的动态图形宣传片已放在 [`showreel`](showreel/) 目录。

- `motion-designer-showreel.mp4`：可直接上传 YouTube 的成片
- `motion-designer-showreel-package.zip`：视频与网页源码压缩包
- `index.html`：HyperFrames 动画网页源码
- `showreel-score.wav`：程序合成音轨

网页预览需要让 `index.html`、`gsap.min.js` 和 `showreel-score.wav` 保持在同一个目录，然后通过本地网页服务器打开。
