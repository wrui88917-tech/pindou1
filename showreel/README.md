# Motion Designer Showreel

规格：15 秒、1920×1080、30fps、H.264 视频、AAC 音频。

## 下载

在 GitHub 文件页面点击 `motion-designer-showreel.mp4`，再点击右上角的下载按钮；也可以下载 `motion-designer-showreel-package.zip` 获得视频和网页源码。

## 网页预览

解压压缩包后，在本目录运行：

```sh
python -m http.server 8000
```

然后访问 `http://localhost:8000/index.html`。

发布前请在 `index.html` 中将 `hello@yourstudio.com` 替换为你的真实邮箱。
