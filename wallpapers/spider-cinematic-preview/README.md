# 写实原图体感预览

以用户给出的写实蜘蛛侠雨夜近景图为美术方向，保留原图细节；不再绘制低多边形角色。

打开 `index.html` 后选择原图。图片仅在浏览器本地处理，不会上传。可拖动预览，或在 HTTPS / 浏览器支持的安全来源下开启手机体感。提供自然握姿校准、景深强度、构图预设、细雨、微光、省电和 1440×3120 静态导出。

实现为 WebGL 深度视差（2.5D），不是可以 360° 绕看的完整 3D 角色模型。用户提供的原图目前只作为聊天内嵌图可见，并未作为可读取的文件出现在附件中；因此没有假装把它内置到本工程。静态图被遮挡的背景无法靠这个轻幅深度变换真实补全。若提供原始 JPG/PNG，可进一步制作精确人物遮罩和干净背景，再改善边缘处的空间分离。

三个深度预设分别对应用户图一的斜向近景构图、居中主体和整幅轻移。面部与身体主区域使用平缓深度平台，限制位移幅度并预留画面边缘；仍应使用实际原图审看边缘和细节。雨和微光为独立着色器层，均可关闭。

网页运行时零外部依赖。桌面本地测试可在本目录运行 `python3 -m http.server 8000`。手机浏览器如果没有体感数据，可先拖动预览；Android 原生壁纸版本可避免浏览器来源权限限制。

安卓原图体感预览版的说明位于 `../spider-tilt/README.md`。网页自动测试通过 `node verify.mjs` 运行，需要开发机安装 Playwright 1.56.1 和 Chromium；这不影响用户打开网页。可用 `PLAYWRIGHT_MODULE` 指定开发工具安装位置。
